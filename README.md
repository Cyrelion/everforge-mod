# Everforge Mod

The official companion mod for the **Everforge** Minecraft server and modpack.

Everforge is a private/community Minecraft world built around Create and an extended NeoForge modpack.

## Supported environment

- Minecraft Java 1.21.1
- NeoForge 21.1.x
- Create 6.0.10

## Purpose

This repository contains Everforge-specific mod functionality used by the Everforge modpack and server.

It is developed primarily for the Everforge environment. Compatibility with other modpacks is not guaranteed.
