# Changelog

All notable changes to the Everforge Mod are documented in this file.

## 0.4.0

### Added

- Create Logistics Network Manager for naming Create logistics network UUIDs without changing Create's native network model.
- Target-aware Factory Gauge handling, including the exact active panel quadrant under the crosshair.
- Admin commands: `/everforge logistics status`, `name <name>`, `move <name>`, `copy`, `paste`, `list` and `unname`.
- Persistent network names in `config/everforge-logistics-networks.properties`.
- Safe reassignment for Factory Gauges and logistics-linked Create blocks while preserving their other settings.

## 0.3.9

### Added

- Local JSONL audit log for commands submitted in-game by privileged players. Console and RCON commands are excluded.
- OpenPAC AutoMode for Everforge server claims. When enabled, players with effective build access are switched to Creative while inside eligible server claims and restored to their previous game mode afterwards.
- Admin commands: `/everforge automode on`, `/everforge automode off`, `/everforge automode status`.
- Persistent server setting `config/everforge-server.properties` with `autoMode=false` by default.

## 0.3.8

### Added

- `/mapsurvey start west` starts the survey from the player's current position and scans the first lane westbound.
- `/mapsurvey start east` starts the survey from the player's current position and scans the first lane eastbound.

### Changed

- Current-position starts use the player's current Z coordinate as the first survey lane and continue the snake pattern toward the configured southern Z bound.

## 0.3.7

### Added

- Client-side Map Survey mode for continuously revealing large Xaero map areas while flying in Spectator or Creative mode.
- Snake-pattern survey traversal with configurable bounds, altitude, lane spacing and flight speed.
- Map Survey client commands: `/mapsurvey start`, `/mapsurvey pause`, `/mapsurvey resume`, `/mapsurvey stop`, `/mapsurvey status`, `/mapsurvey reload`, `/mapsurvey speed <blocksPerSecond>`, `/mapsurvey spacing <blocks>`, `/mapsurvey altitude <y>` and `/mapsurvey bounds <xMin> <zMin> <xMax> <zMax>`.
- Persistent client survey configuration in `config/everforge-map-survey.properties`.

### Changed

- Default Map Survey area set to X `-16000..20000`, Z `-10000..20000` with lane spacing `272`.
- Default Map Survey altitude set to Y `550` for terrain generated by Lithosphere.
