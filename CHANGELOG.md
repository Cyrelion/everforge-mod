# Changelog

All notable changes to the Everforge Mod are documented in this file.

## Unreleased

### Added

- OpenPAC AutoMode for Everforge server claims. When enabled, players with effective build access are switched to Creative while inside eligible server claims and restored to their previous game mode afterwards.
- Admin commands: `/everforge automode on`, `/everforge automode off`, `/everforge automode status`.
- Persistent server setting `config/everforge-server.properties` with `autoMode=false` by default.
